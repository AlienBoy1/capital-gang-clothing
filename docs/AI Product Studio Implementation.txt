Quiero implementar un nuevo módulo completamente independiente llamado "AI Product Studio".

IMPORTANTE:

Este módulo NO debe depender del CRUD de productos existente.

Su función será generar, administrar, organizar y preparar Assets mediante IA.

Los productos seguirán existiendo en su propio módulo.

AI Product Studio solamente preparará contenido listo para publicarse.

5. FLUJO DE USUARIO IMPLEMENTADO
----------------------------------------------------------

1. Dashboard → AI Studio → Nuevo proyecto
2. Abrir proyecto → subir fotografías (AIUploader → /api/upload)
3. Cada foto crea un AIAsset + Versión 1 ORIGINAL (READY)
4. "Procesar todo" o barra de acciones → regenerar pipeline:
     BACKGROUND_REMOVED, WHITE_BACKGROUND, BLACK_BACKGROUND,
     PNG, WEBP, JPG, THUMBNAIL, MOCKUP
   Cada resultado = nueva versión (nunca overwrite)
5. Galería DAM: grid/lista, buscar, filtrar, ordenar, favoritos
6. Timeline / Historial / Comparador por asset
7. Seleccionar assets → PUBLICAR AL CATÁLOGO
8. Se crea CatalogPublishSession (1h TTL)
9. Redirect a /dashboard/productos?publishSession=...
10. ProductManager precarga imágenes por referencia
11. Usuario completa datos comerciales y Guarda
12. ProductImage apunta a assetVersionId + CatalogPublication ACTIVE


----------------------------------------------------------
6. PROCESAMIENTO (estado actual — 100% GRATUITO)
----------------------------------------------------------

Modelado de producto SIN APIs de pago ni AI Gateway:

  1. Recorte local ONNX (@imgly/background-removal-node)
     elimina el fondo de la foto cruda (sin API key).

  2. Se genera un cutout transparente + sombra de contacto.

  3. Variantes locales (fondo claro/oscuro, PNG/WEBP/JPG, thumb, mockup)
     + sello Capital Gang incrustado en cada variante.

No requiere AI_GATEWAY_API_KEY ni créditos de Vercel.

La primera ejecución descarga el modelo ONNX (~80 MB) desde IMG.LY
(gratuito). Luego corre offline en el servidor Node.

Jobs: ai_processing_jobs (PENDING → PROCESSING → COMPLETED/ERROR).
Toasts nativos en dashboard para éxito / error.
